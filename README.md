# 校园失物招领平台

江苏省张家港中等专业学校校园失物招领平台，学生端与管理端共用一套本地数据。

## 功能

学生端：

- 登录后进入首页
- 浏览寻物、招领信息，按分类和关键词查找
- 发布寻物或招领信息，发布后立即展示
- 上传物品照片；没有照片时显示物品分类图标
- 在“我的发布”里查看自己发布的信息，并标记已归还

管理端：

- 教师登录
- 查看工作台数据
- 信息管理：置顶、取消置顶、删除
- 分类管理：新增、编辑、删除
- 学生账号：停用、恢复
- 操作记录
- 重置演示数据

## 数据说明

数据保存在浏览器本地：

- `localStorage`：账号、信息、分类、日志
- `IndexedDB`：上传的物品照片

管理端登录页和侧边栏都有“重置演示数据”，会恢复到初始的 18 条信息、6 个分类、8 个账号，并清除上传图片。

## 说明

- 学生发布后直接展示，没有审核步骤。
- 管理端只负责删除和置顶，物品归还是由发布人在学生端标记。
- 当前是静态演示版本，不连接服务器，换浏览器或清站点数据后内容会恢复为初始数据。
